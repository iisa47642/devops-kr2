# Ошибки шаблона

Номера строк относятся к исходному коммиту `3ee6c4b`.

| № | Файл и строка | Ошибка | Последствие | Исправление |
|---|---|---|---|---|
| 1 | Dockerfile:1 | python:latest | При новой сборке может измениться версия Python. | python:3.12-slim, как в ПР 7. |
| 2 | Dockerfile:5–6 | Весь проект копируется перед pip install. | Изменение app.py вызывает повторную установку библиотек. | Сначала requirements.txt и pip install, затем app.py. |
| 3 | Dockerfile:5; нет .dockerignore | В контекст попадают .env и .git. | Пароль и история Git могут оказаться в слоях образа. | Исключил .env и .git, копирую только нужные файлы. |
| 4 | .env:1; нет .gitignore | Файл с паролем отслеживается Git. | Пароль доступен читателям репозитория и остаётся в истории. | Удалил .env из текущей версии, добавил в .gitignore; на VM создан новый пароль. |
| 5 | Dockerfile:3–9 | Не задан USER. | Приложение работает от root внутри контейнера. | Создал пользователя app и добавил USER app. |
| 6 | Dockerfile:9 | CMD в shell-форме. | Сигнал остановки получает оболочка; Gunicorn может не завершиться вовремя. | CMD записан JSON-массивом. |
| 7 | Dockerfile:9 | Gunicorn слушает 127.0.0.1 внутри контейнера. | Проброшенные подключения приходят на сетевой интерфейс контейнера и не достигают приложения. | Внутри контейнера — 0.0.0.0, публикация на VM — только 127.0.0.1. |
| 8 | Dockerfile:8–9 | Указан порт 8000. | Не выполняется условие варианта 1. | Используется порт 8001. |
